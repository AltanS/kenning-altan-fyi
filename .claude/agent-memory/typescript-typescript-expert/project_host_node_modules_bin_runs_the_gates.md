When `toolbox run -c ts-dev` is unavailable, the repo's own binaries run on the
host: `node_modules/.bin/oxlint --max-warnings 0`, `node_modules/.bin/tsc`
(TS 7, ~3 s), and `node --import tsx --experimental-test-module-mocks --test
"tests/unit/**/*.test.ts"`. `pnpm typecheck` also runs `react-router typegen`;
bare `tsc` skips that step and is enough unless routes changed.

`sqlite3` exists at `/home/linuxbrew/.linuxbrew/bin/sqlite3`, so a hand-written
binary reader (M208 `sqlite-table-reader.ts`) can be hash-checked against the
real engine instead of trusted.

**Why:** the M208/01 brief said there was no sqlite3 and maybe no toolbox; both
were reachable. **How to apply:** probe with `which` before declaring a tool
missing. New `tests/integration` env preconditions must be added to
`SKIP_GUARD_PATTERN` in `tests/unit/integration-tests-self-skip.test.ts`
(WIKDICT_PROBE was). Related: [[project_verify_commands]],
[[project_integration_skip_guard_must_be_inline]].
